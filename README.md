# 🚀 Full-Stack React + TypeScript Application

A modern full-stack web application built using **React, TypeScript, Vite, and Node.js**.  
This project demonstrates frontend architecture, backend API integration, environment configuration, and production-ready structure.

---

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- CSS

### Backend
- Node.js
- TypeScript
- Custom API server (`server.ts`)

## ⚙️ Installation & Setup

### Prerequisites
- Node.js (v18+ recommended)
- npm

---

### 1️⃣ Install Dependencies

```bash
npm install
```

---

### 2️⃣ Environment Variables

Create a `.env.local` file in the root directory and add:

```env
GEMINI_API_KEY=your_api_key_here
```

---

### 3️⃣ Run Development Server

```bash
npm run dev
```

The frontend will start on:

```
http://localhost:5173
```
